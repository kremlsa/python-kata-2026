Задание 1. Проверка идентификатора
Базовое
Реализуй функцию:
def validate_user_id(value: object) -> int:    ...



Требования: принимать только положительные целые числа, запрещать bool, строки, float, None и ноль. При ошибке выбрасывать ValueError.

Проверочные случаи:
Вход	Ожидаемый результат
123	123
0	ValueError
-5	ValueError
"123"	ValueError
True	ValueError
123.0	ValueError
None	ValueError

Задание 2. Валидация уровня критичности
Прикладное
Напиши функцию:
def normalize_severity(value: str) -> str:    ...



Функция принимает значения critical, high, medium, low независимо от регистра и пробелов по краям. Возвращает нормализованную строку в верхнем регистре.

Для любого другого значения, включая значения неподходящего типа, выбрасывает ValueError.

Примеры:
normalize_severity(" high ")   # "HIGH"normalize_severity("CRITICAL") # "CRITICAL"normalize_severity("unknown")  # ValueErrornormalize_severity(None)       # ValueError



Не используй регулярные выражения. Здесь достаточно базовых операций со строками.
Задание 3. Найди дефекты безопасности
С подвохом
Рассмотри код:
def can_access(user_id, is_admin):    if user_id and is_admin:        return True    return False



Найди минимум три проблемы, связанные с обработкой входных данных и проверкой доступа.

Предложи улучшенную реализацию при следующих условиях: user_id — строго положительный int, is_admin — строго bool. Функция должна возвращать False для некорректных аргументов.

Считай, что is_admin получен из доверенного серверного механизма авторизации. Подумай, почему это допущение принципиально важно.
