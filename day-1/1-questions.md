Контрольные вопросы
1. Чем отличаются `==` и `is`?

оператор == проверяет равенство значений объектов
оператор is проверяет идентичность объектов


2. Почему `isinstance(True, int)` возвращает `True`?

True является подтипом int


3. Чем опасна проверка `if not value` при валидации API?

Проверка даст одинаковый результат True как для 0 так и для "" так и для None
Разные варианты ответ один

4. Почему `bool('False')` возвращает `True`?

Это непустая строка


5. Достаточно ли проверки `role == 'admin'` для авторизации?

Зависит от контекста, если это атрибут запроса, поступает из недоверенного источника то недостаточно.
